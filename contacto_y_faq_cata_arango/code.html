No prometemos soluciones instantáneas. Acompañamos procesos maduros de integración psicosomática y descompresión.

Queremos que el proceso sea completamente transparente. Las mentorías van desde $78 USD para la sesión individual de reconexión, $212 USD para el Proceso de Despertar de 3 sesiones, hasta $995 USD para el acompañamiento VIP trimestral. Aceptamos pagos seguros mediante Bold (tarjetas de crédito/débito internacionales), Nequi y transferencias Bancolombia para consultantes en Colombia y el resto del mundo.
